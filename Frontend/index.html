ABOUT

The Classroom Reservation System is designed to help teachers and students easily reserve and schedule classrooms in an organized and efficient way. Its main purpose is to prevent conflicts, overlapping reservations, and confusion in room assignments by providing a centralized system where all requests and schedules can be managed properly.

Through this system, users can check room availability, select suitable time slots, and reserve classrooms based on their needs. It ensures that every class, meeting, or academic activity has an assigned room without interfering with other scheduled reservations. By automating the scheduling process, the system reduces manual errors, avoids double-booking, and makes classroom management more convenient for everyone.

How It Works?

1. User enters the Login/Sign Up page.

The user chooses whether to log in or sign up as a Student or Teacher/Admin.

2. The system identifies the user role.

After logging in, the system checks if the user is a student, teacher, or admin.

3. The correct dashboard appears.

The dashboard shown depends on who logged in. The name of the logged-in user will also appear.

4. Students can request classroom bookings.

If the user is a student, they can only view the schedule on the main dashboard and send a classroom reservation request.

5. Teachers and admins can approve reservations.

If the user is a teacher or admin, they can view the schedule on the main dashboard and approve or manage classroom reservation requests.

6. Only admins can view the user list.

The user list is only visible to the admin. Teachers and students cannot access it.

7. The schedule is shown on the main dashboard.

Both teachers and students can see the classroom schedule on the dashboard to check room availability.

8. Approved requests are added to the schedule.

Once a reservation request is approved, it becomes part of the official classroom schedule.

9. The system helps avoid conflicts.

Because all bookings are recorded in one system, it helps prevent overlapping schedules and double booking.
